# 3.14：都市と交通のレビューを実装へ反映

2026-10-05。3.13で挙げた問題のうち、通勤の採用、実現した需要に応じた所得・投資、住宅、地形アクセス、既存交通の増強を変更した。都市化の倍率を一律に上げる変更ではない。

## 実装内容

| 項目 | 変更した計算 |
|---|---|
| 通勤と求人 | 潜在的な応募と実際の採用を分離。運賃・移動条件・支払能力・容量を満たして通勤が成立した人数だけ求人枠から引く。潜在応募は交通計画用に別途保存し、求人数・応募者数で上限を設ける。 |
| 所得 | 生産しただけの売れ残りは所得に含めない。販売・自家消費に回った数量を基準価格で評価し、原材料費相当を控除する。交易の現金決済とは区別する。 |
| 事業投資 | 生産能力ではなく実現した販売・消費を投資先の評価に使う。隣接区だけでなく、既存交通で到達できる区も候補にする。新たな設備の一部をそこへ配置し、既存設備は瞬間移動させない。 |
| 住宅 | 産業設備とは独立した住宅容量を保持。人口、転入、空室、所得、現金、傾斜、用地、年内の建設可能量で増築を制約し、建設費を支払う。設備投資によって無料で住宅が増える扱いを廃止。 |
| 道路外の移動 | 近距離は海の区を通らない格子経路を調べ、登り降りの費用を加える。遠方は既存の地形アクセス経路と明示的な交通網を使う。同一陸塊だから直線移動できる、という代替経路を削除。 |
| 建設の便益 | 実交通と新設評価で同じ近距離アクセス関数を使用。未接続の場所への便益が無限大にならないよう、旅客・品目別に支払意思の代理上限を置く。 |
| 容量増強 | 利用率80%以上の稼働区間で、便益・状態・資金を満たせば容量を25%増やす。受益区から建設費を調達し、維持費も増える。増強容量は翌年にリセットしない。 |
| 同種交通の乗換 | 鉄道・高速鉄道の分岐で大きく方向を変える場合に、乗換待ち時間の代理費用を追加。単なる途中駅の停車と区別する。 |
| 集積範囲 | 粗い検証用格子で近隣集積の物理的範囲が過大になるのを抑制。1km格子の反復回数は維持する。 |

## 抽象化と係数

- 近距離経路は最大24km（検証用の粗い格子では2区分を下限）で、交互に縦横へ進む2本の候補を比較する。既存の地形アクセス木も使う。全区間で最短経路を探索する方法ではなく、複雑な迂回経路を見逃す余地は残る。
- 通勤候補は少数に限定する。成立しない応募による求人枠の消費は解消したが、全国で最適な雇用マッチングを解く方式ではない。
- 所得は固定基準価格による実現付加価値の代理値。自家消費も含む。企業と家計の現金勘定の完全分離や、実売価に基づく厳密な企業会計は未実装。
- 住宅建設費は居住容量1人分につき2.5×（1＋傾斜×3）。年間建設は既存容量の6%＋1以内、資金は食費相当を除いた現金の4%と年間所得の8%以内。土地上限は居住適性と事業設備の利用面積代理値から求める。
- 増強費は既設資産額の12%、維持費は8%増。容量は初期設計の4倍まで。増便・運用改善・小規模設備増強をまとめた翌年供用の抽象モデルであり、大規模複線化の個別工期は表していない。
- 鉄道の分岐は同種接続が3本以上あり、進行方向の変化が60度を超える場合に乗車費用の半分を追加する。時刻表や運行系統を保持していないため、直通・乗換の実態を完全には再現しない。
- 係数はモデル上の仮定で、実測都市に対する校正は未完了。人口・生産が必ず増えるようにする補正ではない。

## 保存

3.13以前のモデル3保存を読み込める。読込時に従来の住宅容量を引き継ぎ、以後は独立して更新する。新しい保存は住宅容量の拡張データを持つため、3.14以降で再開する。人口や乱数の既存データを破棄して新規生成し直す必要はない。同じ旧保存でも、将来の推移は3.13とは変わる。

## 検証

- Rustの個別試験18件が通過。新たに、通勤不能者による求人枠占有、売れ残りと所得、住宅の独立性・有償建設・保存、地形アクセス、無資金時の増強禁止と翌年の容量維持を検証した。
- 3.13の実際のWASMが作った3年目の保存を読込み、住宅拡張を保存できた。再読込後の翌年は連続実行と保存バイナリーが一致した。
- 配信用WorkerをNodeの接続アダプターで実行。交通計算中の停止、確定年への復帰、意図的なエラー後の巻戻し・再試行を確認した。ブラウザー画面操作の試験ではない。
- 型検査と配信用ビルドが通過した。
- 2000×2000区、シード42で6年まで実行。各年の計算エンジン所要時間は7.30、7.44、7.71、7.75、32.47、31.88秒。6年目のメモリーは約557MiB。保存圧縮・描画を除く単回測定であり、PC状態にも依存する。
- フルサイズ6年目は人口約7,147万人、食料充足94.34%、現在の定義による市街地9集積・約18.6万人。稼働道路757区間、建設中は道路142・鉄道6・高速道路2・高速鉄道7区間。初期6年の結果であり、都市化や幹線接続が十分改善したという証拠ではない。

- 80×80区の補助試験ではシード42で137年、18・108で各30年まで実行し、人口・物資・資金・維持費配賦の誤差が試験の許容値内で、保存再開後の翌年も一致した。シード42は300年を指定したが、240秒の実行予算を超えた137年で終了した。300年完走ではない。
- 80×80区は1区25km四方で、市街地や街路の形の検証には使えない。シード42では25年目以降の人口減少と、長期の食料不足が残った。数値収支の通過を、都市形成の現実性の証明とは扱わない。
- 長期・性能測定後、旧保存の過密地区を移行するときに住宅容量を無料で増やさないよう最終修正した。新規生成から3シード各8年の保存結果が測定版と一致すること、最終版で旧保存移行・Worker復旧が通ることを再確認した。

ブラウザー操作・公開後の確認と、400万区の長期実行、実在都市に対する校正は未実施。

## 残る課題

品目量と旅客人数の車両相当量への統一、企業・家計の厳密な会計分離、運行系統・時刻表、住宅の建替えと老朽化、通勤による機能的都市圏の統計は未実装。新設・延伸・区間廃止の従来処理は存続する。今回の変更だけで実在都市と同様の交通網が必ず形成されるとは断定しない。
