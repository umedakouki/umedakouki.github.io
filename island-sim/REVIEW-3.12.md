# 3.12：需要地と路線・駅のずれを見直す

2026-10-04。コードの候補生成・接続・乗降・容量評価をレビューして修正した。利用者指定により実行試験・長期検証・公開後確認は省略。以下の原因はコード上で確認したものであり、特定の地図上の現象を再現して原因を確定したものではない。

## 原因と修正

| 段階 | 従来の問題 | 3.12 |
|---|---|---|
| 端点 | 需要地を近くの既存駅へ置き換える。鉄道12km、高速道路18km、高速鉄道30km以内の駅に吸着し、元の需要地を失う場合があった | 元の需要地を結ぶ案を残し、駅への接続案と比較 |
| 接続方向 | 接続案の先頭2組だけを評価。右端側の延伸や既存線同士の接続を落とす場合があった | 重複を除いた全端点案、最大5組を評価 |
| 候補枠 | 各需要分類で最大需要1件と巡回1件のみ | 最大需要2件と巡回1件。毎年同じ上位1件だけが優先される偏りを軽減 |
| 経由地 | 主要な途中需要地を最大1か所だけ経由 | 直行・1か所経由・最大3か所の連続経由・既存線活用を比較。同一形状は重複評価しない |
| 駅・IC | 近くの探索範囲に十分な需要がないと駅探索そのものを終了 | 路線全体を探索。人口の少ない区間の先も候補にし、需要の強さと最小駅間隔で選択 |
| 乗降駅 | 出発側・到着側で最寄り1駅を別々に選ぶため、同じ駅になって経路を捨てる場合や、少し遠い駅を使う有利な経路の見落としがあった | 計画評価は各側最大3駅、最大9組から全体費用の小さい組合せを選択 |
| 実際の利用 | 各交通種類で最寄り1駅しか地上アクセス候補にせず、そこが行き止まり・別路線なら近くの利用可能な駅を見落とす | 地形・道路を使う探索で、種類ごとに異なる2駅へのアクセスを保持。通勤・訪問・貨物の既存の経路比較へ接続 |
| 容量 | 異なる区間を使う短距離需要まで路線全体で合算し、全便益を一律に減衰。新線で改善しない移動まで容量を消費させていた | 乗降間の区間に需要を積み、各移動が使う区間の混雑だけで便益を制限。費用改善のない移動は新線の需要に含めない |
| 重複判定 | 両端が既設端点から8km以内というだけで新案を除外 | 同一端点と同一物理区間の重複を判定。別の需要地への支線を距離だけで除外しない |
| 交差と駅の実体 | 同じ種類の既存線と交差しても途中接続点にならない場合がある。また、再利用する既設線上に計画上だけ駅が現れる場合があった | 同一格子上の単独交点を接続候補にする。既設線上の追加駅は実際に分割・接続し、費用と維持費を計上 |

## 判断の流れ

区間の旅客・貨物需要 → 実際の需要地と既設駅を端点候補にする → 地形を考慮した複数の線形を作る → 駅・ICを選ぶ → 乗降駅の組合せと区間ごとの容量を評価 → 建設・維持費と資金を比較。

「人口の多いところをすべて結ぶ」という強制は行わない。同じ需要でも、既存道路が十分便利、運賃・乗換・駅アクセスの負担が大きい、地形上の建設費が高い、資金が不足する場合は見送る。高速鉄道を必ず発生させるための費用引下げは行っていない。

## 容量計算

各乗降区間へ期待利用量を加算し、区間の採用率を `min(1, 容量/期待利用量)` とする。それぞれの移動には、利用区間中で最も低い採用率を適用する。別の区間だけを使う人は互いに混雑させない。同じ区間を使う人と貨物は容量を共有する。

これは配分を単純化した計算で、混雑で乗れなかった需要を別経路へ再配分する完全な均衡計算ではない。また、計画の沿線抽出外の既存利用者との競合をすべて再計算するものではない。

## 制約・係数

- 駅・ICの最小間隔：鉄道5km、高速道路12km、高速鉄道30km。既存の接続点は例外。
- 連続経由案：端点間を長手方向の3帯に分け、各帯の需要地を最大1か所選ぶ。各点を地形探索でつなぎ、自己交差する案や、総延長が直線距離の1.65倍＋4メッシュ幅を超える案を除く。
- 実経路への駅アクセス：種類ごとに近い2駅、地上アクセス費用3時間相当まで。計画評価の3駅候補とは探索方法が異なり、完全には一致しない。
- 同種路線の接続は同一格子上の交点を対象とする。図上の斜め交差すべてを接続するものではない。
- 既設線への追加駅は、既存の駅改修モデルと同様、支払時に開設する簡略化。新設区間自体は従来の建設期間を必要とする。
- 長い路線を採用しやすくするために、便益単価・建設費・資金上限を緩めてはいない。

## 残る限界

都市の需要は区の人口・産業・通勤・需給から計算しているが、候補を有限個に絞るため、すべての有望路線を探す保証はない。駅配置は需要順位と間隔による近似で、全駅の組合せ最適化ではない。地上アクセスの一部と複合経路の投資評価にも近似が残る。

比較案と駅アクセス候補を増やしたため、計算時間・メモリ使用量は増える。今回の実測は省略している。ビルド成功と、実際の地図で有用な交通網が形成されることは別に扱う。

保存形式3を維持する。既存の世界でも、次の年送りから新しい路線計画・利用経路の計算を適用する。既存線を一括で作り直す処理は行わない。
