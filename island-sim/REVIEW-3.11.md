# 3.11：職住分離と通勤による都市圏の形成

2026-10-04。人口を移さずに別の区で働く仕組みを、生産・賃金・交通へ接続した。実行試験、長期シミュレーション、公開後確認は利用者指定により省略。都市形成の改善度や安定性を確認済みとするものではない。

## 何が変わるか

これまでは通勤相当の移動量があっても、労働は居住区の生産だけを支えていた。今回は以下の順序で計算する。

1. 前年の販売、生産設備、所得、今年の労働可能人口と交通網から、居住区と勤務先の区を対応させる。
2. 居住区の労働から通勤者を差し引き、勤務先の第二次・第三次産業へ加える。第一次産業には居住区に残る労働を使う。
3. 通勤者は年間往復400回分の容量と運賃を使う。運賃を払えない、通勤費用が高すぎる、容量が足りない場合は就業割当を減らす。
4. 生産・交易は勤務先で計上。勤務先でのサービス購入も、居住区の需要と予算から決済する。
5. 売れ残りを反映した就業実績を居住区へ戻す。賃金は勤務先の資金から居住区へ移す。
6. 居住区の就業率・所得は既存の移住、出生条件、次年の需要へ接続。企業の生産・販売実績は既存の設備投資へ接続する。

人口は居住区に残る。国内人口移動とは別の勘定である。居住人口＋流入通勤−流出通勤から昼間の密度をつくり、生産の集積効果へ使用する。人口地図と市街地の観測定義は居住人口のまま。

## 二重計上を避ける扱い

- 通勤者は居住区と勤務先の両方で働かない。勤務先への追加労働は第二次・第三次産業に限定する。
- 勤務先で実際に使われた労働を、地元労働者と流入通勤者へ配分する。未使用の設備能力を就業人数とはしない。
- 従来の「就業者数×400回」の代理移動は削除。実際の通勤は生産前に一度だけ交通容量へ計上する。買物・訪問の移動は別に計算する。
- 賃金は国内の資金移転で、通勤を理由に貨幣を生成しない。勤務先の所得から支払分を差し引き、居住区へ同額を加える。居住区の所得は通勤運賃を控除する。
- サービスの売れ残りによる就業減少は都市産業に適用し、農林水産業の就業を一緒に減らさない。
- 通勤候補の割当は、送り出す区の労働予算と勤務先の募集枠を減らしながら行う。同じ労働者・募集枠から際限なく潜在交通需要を作らない。

## 交通整備へ戻す需要

交通費・容量に阻まれた通勤候補も、道路・鉄道・高速道路などの既存の新設評価へ渡す。ただし、成立していない通勤は実際の旅客数、生産、所得には含めない。新設には既存の費用便益評価・資金制約が引き続き必要。既存路線の維持評価には実際に成立した通勤の利用・便益を加える。

区の候補は近隣区、16km空間区画内の設備・販売がある区、交通で到達する24接続点の区から抽出し、最大6候補に絞る。都市や都市圏の位置は指定しない。接続点や空間区画は探索の索引であり、労働・生産・賃金の配分単位ではない。

## 主な係数と抽象化

| 項目 | 初期設定・意味 |
|---|---|
| 通勤可能な割合 | 居住労働力の最大35%。食料不足時は居住区の労働保留を増やす |
| 募集枠 | 設備による都市産業の雇用能力×販売利用率の補正−居住労働の35%、下限0 |
| 候補の距離 | 最大100km。実際の成立は経路の一般化費用1.5以下などでさらに制限 |
| 一般化費用 | 駅等へのアクセス、移動、乗換、運賃相当を含む指標。「実時間90分」と同義ではない |
| 通勤頻度 | 年200日×往復2回＝400回 |
| 運賃 | 1回あたり0.002＋一般化費用×0.004、モデル基準金額 |
| 賃金原資 | 実現した都市産業の所得指標の60%に、都市労働中の流入通勤割合を掛ける |
| 支払限度 | 勤務先の生活予備資金を除く現金の50%以内。現金不足分を架空の賃金として発行しない |
| 通勤先の購入 | 勤務先での訪問消費に相当。既存のサービス需要・予算・在庫を上限とする |

人口は人、就業と通勤は年間の人数相当、交通需要は年間延べ片道人数。金額は円ではなくモデル基準額。係数は実測による校正前の仮定。

## 保存と表示

人口・設備・生産・所得・資金は従来どおり保存する。年内の通勤割当は毎年再計算する作業用データで、保存形式3には追加しない。保存読込直後は「通勤・職場」の内訳を未取得として表示し、次の年送りで表示する。年内の通勤実績は年末の人口移動前の人数なので、年末の居住人口や就業率と単純には一致しない。

右側の「通勤・職場」は初期状態で折りたたみ、必要時に区外への通勤、区外からの通勤、勤務先での就業、受取賃金、通勤費を表示する。

## 根拠と限界

[Monte, Redding & Rossi-Hansberg：Commuting, Migration and Local Employment Elasticities](https://www.nber.org/papers/w21706) は交易・通勤・移住による地域間のつながりを扱う。[Redding：Suburbanization in the United States 1970–2010](https://www.nber.org/papers/w28841) は勤務先・居住地の魅力と通勤費用を区別する。本実装はこの区別を採用した簡略モデルであり、論文の均衡モデルや推定係数を再現したものではない。

全員について職種・技能・雇用契約を持たせず、区単位の人数を最大6候補へ順に配分する。探索順は毎年回転するが、完全な労働市場均衡ではない。年内は通勤割当を固定し、売れ行きによる稼働低下は年末の実績へ反映する。年内の再就職や転職は省略する。

通勤は現在の複合交通の経路探索を利用する。駅へのアクセス・道路・鉄道等の容量を扱う一方、同一陸地内の徒歩等の代替経路に近似があり、全移動の地形・信号・時刻表を厳密に解くものではない。通勤道路の混雑も末端アクセス区間は簡略化される。

賃金は区の事業・家計を合わせた勘定から支払うため、企業会計と家計会計の完全な分離ではない。物資の売れ残りは在庫として残る既存モデルを引き継ぐ。今回の変更だけで都市化や人口増加を保証しない。
